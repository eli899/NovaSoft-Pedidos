# NovaSoft Pedidos

Proyecto académico que simula un sistema web básico para la gestión de pedidos.

## Funciones

- Registrar el nombre de un cliente.
- Seleccionar un producto.
- Indicar la cantidad solicitada.
- Calcular el total del pedido.
- Mostrar los pedidos registrados.

## Tecnologías

- HTML
- CSS
- JavaScript
- Git y GitHub

## Propósito

Demostrar operaciones de control de versiones como creación de ramas,
reversión de cambios, recuperación de archivos, resolución de conflictos
y etiquetado de versiones.
